# Student-Attendance-Management-System

A Java-based application designed to manage student records, courses, class sessions, and attendance efficiently. The system uses a database to store and organize academic information.

## Features
- Student registration and management
- Add, update, delete, and search student records
- Course and class session management
- Attendance record management
- Database integration for persistent data storage
- User-friendly graphical interface

## Technologies Used
- **Language:** Java
- **Database:** SQL
- **IDE:** IntelliJ IDEA
- **Data Structures:** Lists and ArrayLists

## Project Structure
- `src/` — Java source code
- `DatabaseInitializer` — Database table initialization
- `DAO/` — Database operations and data access
- `model/` — Application data models

## Getting Started
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Configure the required JDK and database.
4. Run the main application class.

## Purpose
This project was developed as an academic assignment to apply Java programming, database management, and data structures in a practical student attendance management system.
